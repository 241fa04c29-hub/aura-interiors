# Aura Interiors
Responsive interior marketplace and room customisation website prototype.

## Run
Extract the ZIP and open `index.html` in a modern browser, or use VS Code Live Server.

## Features
- Aura Essential, Aura Signature and Aura Luxe packages with image references and inclusion lists.
- Product catalogue with Hettich, Häfele, Ebco, Olive, Greenlam, Merino, Rehau, CenturyPly, Greenpanel and Ozone.
- Expanded image-led product ranges across cabinetry, hardware, surfaces, storage, lighting and accessories, with sample finish and size options on every product.
- Search and filters by room, category and brand.
- Interactive 3D-style room studio with room and finish controls, drag-to-orbit preview, add/move/resize/remove furniture, per-room saved layouts, and a one-click save to the design plan.
- Product and finish visuals are locally generated SVG illustrations matched to the item type; they are illustrative, not supplier SKU photography.
- Add-to-cart, quantity controls, remove item and quotation-request demo.
- Material planner and rule-based suggestions.
- Demo account, saved products, cart and design plan stored in localStorage.

## Important
Catalogue, dimensions, model availability and prices are illustrative sample data. The room hero and package images are external Unsplash references; catalogue item illustrations are local SVGs and do not claim to show exact supplier models. Verify exact SKUs, sizes, finishes, technical ratings, stock, product photographs and prices with authorised suppliers. Package contents and starting prices are examples, not binding quotations. Authentication is demo-only; passwords stored in localStorage are not secure. Production use requires a secure backend, database and authentication. localStorage is browser/device-specific.
